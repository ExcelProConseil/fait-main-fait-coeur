Comment enregistrer

  1. Cliquez sur « Copier le texte ».
  2. Cliquez sur « Ouvrir produits.js dans GitHub » (connectez-vous si besoin).
  3. Dans l’éditeur, sélectionnez tout (Ctrl+A) et collez (Ctrl+V).
  4. Cliquez sur « Commit changes » en haut à droite, puis confirmez.
  5. Le site est mis à jour en 1 à 2 minutes.

Photos : dans GitHub, ouvrez le dossier images, cliquez sur Add file → Upload files, déposez la photo, puis « Commit changes ». Écrivez ensuite son nom exact (ex. lapin.jpg) dans le champ « Photo » du produit.
